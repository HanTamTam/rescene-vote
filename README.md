# ✨ RESCENE (리센느) 투표 & 스케줄 대시보드

리센느(RESCENE) 팬덤 리마인(REMINE)을 위한 모바일 최적화 데일리 투표 및 음악방송·어워즈 스케줄 대시보드입니다.

---

## 📱 웹 대시보드 바로가기
- **공식 배포 주소**: `https://hantamtam.github.io/rescene-vote/`
- **핵심 기능**:
  - 접속 당일 요일 자동 감지 및 '오늘 할 일' 우선 노출
  - 시상식(KGMA, MAMA, MMA) 및 주간 6대 음악방송 간트(Gantt) 타임라인
  - 클릭 한 번으로 공식 투표 앱/웹으로 이동하는 퀵 액션 버튼
  - 스마트폰 한 손 터치에 최적화된 모바일 UI
